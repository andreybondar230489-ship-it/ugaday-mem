# Угадай мем — исходный Android-проект v0.3
Реализовано: горизонтальный экран, постоянное разрешение Android на папку (SAF), повторное сканирование изображений, выбор отмеченных мемов по номерам, случайная выборка без повторений, переход к следующему мему.
Не реализовано: Wi-Fi сервер, QR, приём фотографий, таймер, ИИ-оценка, удаление фото. APK НЕ собран и проект НЕ проверен на устройстве.
Сборка: открыть проект в Android Studio с Android SDK 35 и JDK 17, затем Build APK(s). Gradle wrapper не включён. targetSdk 28 — временный параметр прототипа, перед распространением необходимо обновить и протестировать.
